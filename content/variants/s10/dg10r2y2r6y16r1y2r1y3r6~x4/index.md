This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/dg10r2y2r6y16r1y2r1y3r6/)
(the same proportion at any scale), whose colour order is pattern [GRGRGRGRGR](/stripes/grgrgrgrgr/).

Part of the [Nithsdale](/tartans/nithsdale/) tartan — the named design grouping this sett with its other cloths.

Sourced from register-of-tartans.  It is a [10 stripe tartan](/stripes/stripes10/).

Original link https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=3142
