This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/dp2dg16dti16dt2dti2dt2dti2dt15db3lo2/)
(the same proportion at any scale), whose colour order is pattern [BGBBBBBBBY](/stripes/bgbbbbbbby/).

Part of the [Brydon](/tartans/brydon/) tartan — the named design grouping this sett with its other cloths.

Sourced from register-of-tartans.  It is a [10 stripe tartan](/stripes/stripes10/).

Original link https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=10953
