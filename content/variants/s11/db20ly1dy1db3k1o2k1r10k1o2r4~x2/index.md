This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/db20ly1dy1db3k1o2k1r10k1o2r4/)
(the same proportion at any scale), whose colour order is pattern [BYGBKRKRKRR](/stripes/bygbkrkrkrr/).

Part of the [Blais](/tartans/blais/) tartan — the named design grouping this sett with its other cloths.

Sourced from register-of-tartans.  It is a [11 stripe tartan](/stripes/stripes11/).

Original link https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=295
