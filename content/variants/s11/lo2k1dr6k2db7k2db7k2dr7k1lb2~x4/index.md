This is one **variant** — a specific cloth: this exact thread count and colourway, with its own
provenance below. It is one weaving of the [sett](/tartans/m/mo/mount-isla/) (the scale-free proportion — the
same cloth at any scale or shade), whose colour order is pattern [WKBKBKBKBKY](/stripes/wkbkbkbkbky/).

Part of the [Mount Isla](/tartans/m/mo/mount-isla/) tartan — the named design grouping this sett with its other cloths.

Sourced from register-of-tartans.  It is a [11 stripe tartan](/stripes/stripes11/).

Original link [https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=3030](https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=3030)
