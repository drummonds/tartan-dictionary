This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/db1r1db6k6g1b2g9b2g1k6db6r1/)
(the same proportion at any scale), whose colour order is pattern [BRBKGBGBGKBR](/stripes/brbkgbgbgkbr/).

Part of the [MacTaggart](/tartans/mactaggart/) tartan — the named design grouping this sett with its other cloths.

Sourced from register-of-tartans.  It is a [12 stripe tartan](/stripes/stripes12/).

Original link https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=2767
