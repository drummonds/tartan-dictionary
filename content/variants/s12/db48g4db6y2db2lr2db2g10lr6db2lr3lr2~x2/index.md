This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/db48g4db6y2db2lr2db2g10lr6db2lr3lr2/)
(the same proportion at any scale), whose colour order is pattern [BGBGBYBGYBYY](/stripes/bgbgbybgybyy/).

Part of the [Damson](/tartans/damson/) tartan — the named design grouping this sett with its other cloths.

Sourced from register-of-tartans.  It is a [12 stripe tartan](/stripes/stripes12/).

Original link https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=887
