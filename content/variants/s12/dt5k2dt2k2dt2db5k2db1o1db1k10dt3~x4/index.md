This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/dt5k2dt2k2dt2db5k2db1o1db1k10dt3/)
(the same proportion at any scale), whose colour order is pattern [BKBKBBKBRBKB](/stripes/bkbkbbkbrbkb/).

Part of the [Hopkins](/tartans/hopkins/) tartan — the named design grouping this sett with its other cloths.

Sourced from register-of-tartans.  It is a [12 stripe tartan](/stripes/stripes12/).

Original link https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=5140
