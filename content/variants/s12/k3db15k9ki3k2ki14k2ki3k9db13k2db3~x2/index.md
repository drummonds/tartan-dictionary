This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/k3db15k9ki3k2ki14k2ki3k9db13k2db3/)
(the same proportion at any scale), whose colour order is pattern [BKBKKKKKKKBK](/stripes/bkbkkkkkkkbk/).

Part of the [McWilliams](/tartans/mcwilliams/) tartan — the named design grouping this sett with its other cloths.

Sourced from house-of-tartan.  It is a [12 stripe tartan](/stripes/stripes12/).
