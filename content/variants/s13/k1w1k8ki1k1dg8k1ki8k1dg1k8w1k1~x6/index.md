This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/k1w1k8ki1k1dg8k1ki8k1dg1k8w1k1/)
(the same proportion at any scale), whose colour order is pattern [KWKGKKKGKKKWK](/stripes/kwkgkkkgkkkwk/).

Part of the [Chess](/tartans/chess/) tartan — the named design grouping this sett with its other cloths.

Sourced from register-of-tartans.  It is a [13 stripe tartan](/stripes/stripes13/).

Original link https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=5934
