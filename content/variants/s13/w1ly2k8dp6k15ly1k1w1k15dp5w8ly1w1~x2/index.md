This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/w1ly2k8dp6k15ly1k1w1k15dp5w8ly1w1/)
(the same proportion at any scale), whose colour order is pattern [WYKBKYKWKBWYW](/stripes/wykbkykwkbwyw/).

Sourced from register-of-tartans.  It is a [13 stripe tartan](/stripes/stripes13/).
