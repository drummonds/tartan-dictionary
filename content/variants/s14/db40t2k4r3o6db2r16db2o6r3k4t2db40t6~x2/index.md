This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/db40t2k4r3o6db2r16db2o6r3k4t2db40t6/)
(the same proportion at any scale), whose colour order is pattern [BBBKRRBRBRRKBB](/stripes/bbbkrrbrbrrkbb/).

Part of the [St. Leonards](/tartans/st-leonards/) tartan — the named design grouping this sett with its other cloths.

Sourced from register-of-tartans.  It is a [14 stripe tartan](/stripes/stripes14/).

Original link https://www.tartanregister.gov.uk/tartanDetails.aspx?ref=3899
