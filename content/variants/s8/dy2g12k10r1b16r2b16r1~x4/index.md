This page is one **sett** — a single exact thread-count. It belongs to the [tartan](/setts/dy2g12k10r1b16r2b16r1/)
(the same proportion at any scale), whose colour order is pattern [GGKRBRBR](/stripes/ggkrbrbr/).

Sourced from register-of-tartans.  It is a [8 stripe tartan](/stripes/stripes8/).
