Go renderer — component gallery

Every part of a tartan page, rendered by the one Go renderer (internal/render + internal/weave) reached through the WASM engine. This is the test harness for that renderer: change the sett and watch each component redraw from the same place. The static dictionary pages and the in-browser tools both consume exactly these.
